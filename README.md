## ما تم إصلاحه

-   حذف حزمة React 18 + ReactDOM المضمّنة (~ميجابايت من كود مكرر غير مستخدم) وTailwind المضمّن.
-   حذف المتغيرات والدوال غير المستخدمة، والكلاسات المكررة (`force-white`)، ومعالجة `hidden` المزدوجة.
-   استبدال `alert()` القديم بـ Toast أنيق غير معطّل للصفحة.
-   إصلاح منطق الحاسبة: قراءة الأرقام العربية/الفارسية، الفاصلة العربية `٫`، والفواصل، وتقييد المدخلات.
-   إعادة بناء حماية زر الحجز: منع النقر بدون مدة + تهدئة 4 ثوانٍ + حد 12 نقرة/دقيقة.

## الأمان

-   `Content-Security-Policy` صارم عبر `<meta>`: لا سكربتات أو ستايلات مضمّنة، لا اتصالات خارجية.
-   لا `innerHTML` مع أي بيانات متغيرة — كل النصوص تُكتب عبر `textContent`.
-   لا `onclick` مضمّن؛ كل الأحداث تُربط في `app.js`.
-   `rel="noopener noreferrer"` لكل الروابط الخارجية.
-   `maxlength="8"` على حقل المدة + تقييد القيمة داخل JS (`MAX_MINUTES = 10000`).
-   `referrer` محدود إلى `strict-origin-when-cross-origin`.
-   `base-uri 'none'`, `form-action 'none'`, `object-src 'none'`.

> ملاحظة: `frame-ancestors` لا يعمل عبر `<meta>` (المتصفح يتجاهله) — يجب ضبطه من خلال HTTP header على السيرفر إذا أردت منع التضمين داخل iframe.

## إمكانية الوصول

`fieldset/legend`، تسميات `label`، `aria-pressed` لأزرار اللغة، `aria-expanded/aria-controls` للتفاصيل، `aria-live="polite"` للإجمالي والـ Toast، `:focus-visible`، ودعم `prefers-reduced-motion`.
